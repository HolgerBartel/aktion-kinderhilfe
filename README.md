# aktion-kinderhilfe — Website der Aktion Kinderhilfe International e.V.

Statische Website (HTML/CSS, ein kleines Skript nur fuer die Sprachwahl), Deutsch/Englisch, ohne Cookies, Tracker
oder externe Ressourcen. Bereitgestellt ueber GitHub Pages.

- `index.html` Startseite, `impressum.html`, `datenschutz.html`
- `assets/` Gestaltung, Sprachwahl, Bilder (ohne EXIF/GPS, nur Bilder ohne erkennbare Personen)
- `beitrittserklaerung.pdf` leere Beitrittserklaerung

Vorschau-Phase: `noindex` gesetzt; vor der Freischaltung unter eigener Domain entfernen.
Gepflegt von der Privat-Session (Claude) im Auftrag des Vorsitzenden.
